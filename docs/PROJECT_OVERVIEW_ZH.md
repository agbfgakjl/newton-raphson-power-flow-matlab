# 项目思路

本项目把潮流计算拆成一条非常清楚的工程流程：

```text
Excel 节点/线路数据
        ↓
输入校验与标幺化
        ↓
组建节点导纳矩阵 Ybus
        ↓
牛顿—拉夫逊迭代
        ↓
节点电压、相角、P/Q 注入
        ↓
线路双向潮流与损耗
        ↓
越限告警、Excel/CSV、图表和 HTML 报告
```

## 为什么选择 IEEE 14 节点

- 规模小，运行很快；
- 同时包含 Slack、PV、PQ 三类节点；
- 包含线路充电电纳和非额定变压器变比；
- 比自定义五节点案例更容易被电力系统方向的客户和招聘人员识别。

## 项目边界

这是平衡三相、正序、稳态交流潮流工具，不包含故障计算、暂态稳定、最优潮流、无功上下限自动切换和不平衡配电网分析。这些内容可以作为后续版本扩展。
